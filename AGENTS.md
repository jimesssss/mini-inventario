# Instrucciones para Codex
1. Este proyecto es una aplicación web llamada Mini Inventario.
2. Utilizar Node.js 22 y Python 3.12.
3. El servidor web utilizará Express.
4. La interfaz utilizará HTML, CSS y JavaScript sin frameworks.
5. La base de datos será Supabase PostgreSQL.
6. Antes de programar, revisar README.md y docs/.
7. Explicar el plan antes de modificar archivos.
8. Crear una rama Git para cada actividad o cambio.
9. Realizar los cambios mediante pull requests.
10. No subir contraseñas, tokens, llaves ni archivos .env.
11. Mantener las credenciales fuera del código fuente.
12. Solicitar aprobación antes de borrar datos.
13. Solicitar aprobación antes de desplegar la aplicación.
14. No ejecutar operaciones destructivas sin autorización.
15. Comprobar que cada cambio funcione correctamente.
16. Documentar los errores encontrados y sus soluciones.
17. Guardar las evidencias en entregas/dia-XX/.
18. No modificar archivos ajenos a Mini Inventario.
